# MEDUSA CTFd Theme

The MEDUSA CTFd theme is the player-facing presentation layer for the MEDUSA competition platform. It is intentionally isolated from upstream CTFd core and MEDUSA backend/plugin logic.

## Compatibility

- CTFd target: **3.8.8**
- Theme model: CTFd custom theme / core-beta-compatible structure
- Build system: Vite
- Templates: Jinja2
- Styles: SCSS
- JavaScript: browser modules

CTFd themes use Jinja templates and compiled assets. CTFd's `Assets` helpers resolve generated files using `static/manifest.json`.

## Repository layout

```text
medusa-ctfd-theme/
├── assets/
│   ├── js/
│   └── scss/
├── templates/
├── static/                  # generated by the build; ignored in source control
├── package.json
├── package-lock.json
└── vite.config.js
```

## Development

Requirements: Node.js compatible with the installed Vite version and npm.

```bash
npm ci
npm run build
npm run lint
```

Run the Vite watcher during development:

```bash
npm run dev
```

## Asset contract

Every theme asset referenced with `Assets.js` or `Assets.css` must be a named Vite build entry or a generated dependency resolvable from `static/manifest.json`.

Current entrypoints:

- `assets/scss/main.scss`
- `assets/js/app.js`
- `assets/js/challenges.js`
- `assets/js/dashboard.js`
- `assets/js/scoreboard.js`
- `assets/js/settings.js`

When adding a template script, add its source file to `vite.config.js`. Import each SCSS component once from `assets/scss/main.scss`; do not add duplicate `@use` declarations.

## CTFd integration

Mount or copy this repository to `CTFd/themes/medusa` and run the build before starting CTFd. The build must generate `static/manifest.json` in the theme directory.

Use the CTFd `Assets` helper rather than hard-coding generated asset filenames. Never modify CTFd core to implement theme behavior.

## Design boundary

This repository owns MEDUSA visual identity, player-facing templates, presentation state, browser interactions, and asset compilation. Authentication, challenge scoring, competition lifecycle, sandbox orchestration, anti-cheat decisions, and privileged administration belong in CTFd or MEDUSA backend/plugin services.

## Security principles

- Never embed secrets in templates or JavaScript.
- Never expose Kubernetes credentials to the browser.
- Treat server-provided challenge content as untrusted content.
- Avoid unsafe HTML injection.
- Keep dependencies pinned through the lockfile.
- Do not modify CTFd core.

## Contribution checklist

- [ ] Every `Assets.js` / `Assets.css` reference resolves from the generated manifest.
- [ ] New JS entrypoints are registered in `vite.config.js`.
- [ ] SCSS components are imported once.
- [ ] `npm ci`, `npm run build`, and `npm run lint` pass.
- [ ] No secrets or backend-only responsibilities were added to the theme.
