# MEDUSA CTFd Theme

The MEDUSA CTFd theme is the player-facing presentation layer for the MEDUSA competition platform. It is intentionally isolated from upstream CTFd core and from MEDUSA backend/plugin logic.

## Compatibility

- CTFd target: **3.8.8**
- Theme model: CTFd custom theme / core-beta-compatible structure
- Build system: Vite
- Templates: Jinja2
- Styles: SCSS
- JavaScript: browser modules

CTFd themes use Jinja templates plus compiled JavaScript/CSS assets. CTFd's `Assets` helpers read the generated `static/manifest.json`.

## Repository layout

```text
medusa-ctfd-theme/
├── assets/

│   └── scss/

├── static/                  # generated by the build; ignored in source control

```


Build the CTFd assets:

```bash
npm run build
```


```bash

```

## CTFd integration

Copy or mount this repository as a theme under the self-hosted CTFd `themes/medusa` directory and build the assets before starting CTFd. The build must place `manifest.json` at the root of `static/`, where CTFd expects it.

The theme must use CTFd's `Assets` helper for compiled assets. Do not hard-code generated asset filenames because Vite output can change between builds.

MEDUSA-specific business logic belongs in `medusa-ctfd-plugins` or backend services. The theme should only consume CTFd/plugin-provided data and render the player experience.

## Design boundary

This repository owns:

- MEDUSA visual identity
- player-facing templates
- presentation state
- browser-side interaction
- theme asset compilation

This repository does **not** own:

- authentication implementation
- challenge scoring
- competition lifecycle
- Kubernetes credentials
- sandbox orchestration
- anti-cheat decisions
- privileged administration logic

## Security principles

- Never embed secrets in templates or JavaScript.
- Never expose Kubernetes credentials to the browser.
- Treat all server-provided challenge content as untrusted content.
- Avoid unsafe HTML injection.
- Keep dependencies pinned through the lockfile.
- Do not modify CTFd core to implement theme behavior.
